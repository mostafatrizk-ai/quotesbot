# 🚀 WA Outreach Pro — إضافة كروم لحملة واتساب ذكية مضادة للباند

نظام outreach كامل يشتغل **داخل web.whatsapp.com نفسها** — بدون سيرفر، بدون Evolution API، بدون Meta. تفتح واتساب ويب وتلاقي لوحة عربية مدمجة تدير الحملات بسلوك بشري 100%.

## ✨ المميزات
| الفئة | التفاصيل |
|---|---|
| 🛡️ Anti-Ban | حد يومي (80) + تسخين تراكمي (يوم1=20 ثم +20/يوم) + فترات عشوائية 45–120s + كتابة حرف-بحرف بسرعة بشرية + استراحة كل 10 رسائل + سقف جلسة 25 |
| 👁️ Watchdog | يمسح الصفحة باستمرار؛ أي بانر حظر/قيود/Captcha → **E-STOP فوري** بأحمر في الأيقونة |
| 🛑 Opt-out | "إيقاف / stop / unsubscribe / بلاش / لا أريد..." من الردود الواردة = حظر دائم للرقم تلقائيًا |
| 🔁 Dedup | نفس الرقم لا يُراسل مرتين خلال 24 ساعة حتى لو من حملتين |
| 🤖 AI Agent | اختياري (OpenAI أو OpenRouter): تصنيف الردود (interested/question/opt_out)، ردود مقترحة، تحسين نص الحملة، قرار "أراسل الآن؟". **بدون مفتاح يعمل offline بكلمات مفتاحية** |
| 📥 CSV | `phone,name,city,...` → الأعمدة تصير متغيرات `{{city}}` في القالب |
| 💾 الحالة | كل شيء محفوظ في `chrome.storage.local` — تقفل المتصفح وتفتح تكمل |

## 📦 التحميل والتشغيل (دقيقتان)
1. حمّل `wa-extension.zip` وفك الضغط.
2. افتح `chrome://extensions` ← فعّل **Developer mode** ← **Load unpacked** ← اختر مجلد `wa-extension`.
3. افتح [web.whatsapp.com](https://web.whatsapp.com) وسجّل الدخول — اللوحة تظهر شمال الشاشة.
4. تبويب «جهات»: الصق الـ CSV → تبويب «حملة»: اكتب النص بـ `{{name}}` → **▶ ابدأ**.

## ⚙️ اقتراحات تشغيل آمنة
- استخدم رقمًا مخصصًا للحملات وليس رقمك الشخصي.
- أول أسبوعين: لا ترفع الحد اليومي يدويًا — التسخين بيتكفل.
- لو ظهر ⛔ أحمر: اترك الحساب 24 ساعة قبل أي محاولة جديدة.
